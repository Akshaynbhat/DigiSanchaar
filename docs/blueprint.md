# **App Name**: DigiSanchaar

## Core Features:

- Distress Pattern Recognition: Enable users to define a custom pattern (using phone buttons) that triggers SOS activation, reducing false alarms.
- AI-Powered Distress Word Detection: Analyze audio for distress keywords using an AI model when the SOS pattern is activated to understand the emergency context; acts as a tool to help with understanding.
- Automated Emergency Contact Call: Initiate an automated call to the user's emergency contact, prompting them to check their email for live location and audio evidence. Persistently attempt contact until confirmation is received.
- Heat Map of Risk Zones: Overlay crowdsourced reports with machine learning-derived scores identifying unsafe areas.
- Offline SOS via SMS: Allow users to send an SOS and location via SMS if no internet is available, ensuring safety even with limited connectivity.
- Hourly Location Tracking: Track and store user locations on the device every hour to aid in search efforts during emergencies.
- Group Travel Alerts: Notify group members if one goes missing, ensuring that the fellow members are notified.
- Community SOS Alerts: Send an SMS to users within a radius of a confirmed distress signal, alerting them about the emergency and prompting assistance.
- AI-Based Safety Score: Generate a safety score for each trip based on the user's itinerary and location data using AI analysis.
- Blockchain Trip ID: Assign a unique, blockchain-secured trip ID at the start of each trip for enhanced security and verification.
- Automated E-FIR: Automatically generate and submit an E-FIR to the police with relevant evidence upon distress confirmation.

## Style Guidelines:

- Primary color: Safety orange (#FF6B00) to convey urgency and attention.
- Background color: Light gray (#F0F0F0), providing a clean and unobtrusive backdrop.
- Accent color: Teal (#008080), an analogous color used sparingly to draw attention to less frequent elements without causing panic.
- Font pairing: 'Space Grotesk' for headlines, a sans-serif that conveys both tech and clarity; 'Inter' for body text.
- Use clear and universally recognizable icons to represent safety features and alerts. Employ a minimalist style, using icons with simple shapes.
- Design the app layout with a focus on easy navigation and quick access to essential features, particularly the SOS button and emergency contact information.
- Incorporate subtle animations to guide the user and provide feedback. For example, use a pulsating animation for the SOS button during activation.
